Journal personnel du Chef

Ces rapports deviennent irritants. La vélocité de l’agent Romain et celle de l’agent Damien sont strictement identiques, et ce système obstiné s’entête donc à afficher true. Une conclusion bien trop honnête à mon goût ! 

public class Velocite {
    public static void main(String[] args) {
        Integer velociteRomain = 1;
        Integer velociteDamien = 1;

        System.out.println("Vélocité identique ? -> "
                + (velociteRomain == velociteDamien));
    }
}

Heureusement, même les programmes ont leurs faiblesses. Il me suffit de trouver la plus petite vélocité identique (peu importe qu'elle soit vraie) pour que le système affiche stupidement false.

Pour ne pas éveiller les soupçons : je me contenterai de modifier les nombres après chaque signe égal.
